# 🛠️ WorkWhiz – EMPOWRING TEAM ENHANCING SUCCESS

## 📌 Key Features  

### ✅ **Project Management**  
- Create, manage, and delete projects.  
- Assign tasks and track progress in real time.  
- Organize projects with custom statuses (To-Do, In Progress, Done).  

### 👥 **Collaboration & Communication**  
- **User Invitation System** – Invite team members via email.  
- **Comment System** – Discuss issues and track feedback directly within projects.  
- **Issue Management** – Report, assign, and resolve issues seamlessly.  
- **💬 Real-Time Chat** – Communicate with team members instantly using an integrated **WebSocket-based** chat system.  

### 🔒 **Security & Authentication**  
- **JWT Authentication** – Secure login & session management.  
- **Spring Security** – Protect sensitive data from unauthorized access.  

### 💰 **Subscription & Payments**  
- Implement **subscription plans** with Razorpay for premium project features.  
- Track payments and manage user subscriptions.  

### 🔎 **Advanced Search & Filters**  
- Find projects, tasks, or users easily using **dynamic search and filtering**.  

### 🎨 **Modern UI & Responsive Design**  
- Built with **Tailwind CSS** and **ShadCN UI** for a sleek, modern look.  
- Fully **responsive** across desktops, tablets, and mobile devices.  

---

## 🏗️ Tech Stack  

### **Frontend**  
- **React.js** – Interactive, dynamic UI  
- **Redux** – Global state management  
- **React Router DOM** – Smooth navigation between pages  
- **Tailwind CSS & ShadCN UI** – Responsive and modern styling  
- **Socket.io** – Real-time chat integration 


### **Backend**  
- **Spring Boot** – Robust backend framework  
- **MySQL** – Efficient database management  
- **Spring Security** – Secure authentication & authorization  
- **Spring Starter Mail** – Email notifications for invites & updates  
- **WebSockets** – Powering real-time chat functionality  

### **Payment Integration**  
- **Razorpay** – Secure, real-time payment processing
